# 🛍️ Online Shopping System

## Project Overview
The Online Shopping System is a web application developed using Python and Streamlit. It allows users to browse products, search for products, add items to a shopping cart, and place orders.

## Features
- Product catalogue with images and prices
- Search products by name
- Filter products by category
- Add products to cart
- Buy Now option
- Shopping cart management
- Checkout and order confirmation
- Order history

## Technologies Used
- Python
- Streamlit
- JSON
- Object-Oriented Programming (OOP)

## Project Files
- `app.py` – Main application code
- `classes.py` – Contains Product and ShoppingCart classes
- `products.json` – Stores product details
- `requirements.txt` – Required Python packages

## Installation and Execution

1. Clone this repository.
2. Open the project folder in VS Code.
3. Install the dependencies:

   `pip install -r requirements.txt`

4. Run the application:

   `streamlit run app.py`
